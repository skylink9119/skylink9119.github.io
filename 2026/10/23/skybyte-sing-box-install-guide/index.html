sing-box 一键脚本搭建教程：Reality、HY2 与客户端导入

发表于2026-10-23|更新于2026-10-26|技术教程 / 网络链路
|浏览量:
想用什么功能，就按表格选择。
适用 SKYBYTE Manager v2.8.15。主菜单用字母，子菜单用数字，确认输入 y。
a → 1 表示输入 a、回车，再输入 1、回车。表格路径均从主菜单开始；已经在子菜单时，直接选择编号。操作后留在当前菜单，0 返回上一层，主菜单 q 退出。

1. 先安装，再打开脚本

用 root 登录 Ubuntu/Debian VPS，打开安装入口页，点击“复制安装命令”，粘贴到 VPS 终端执行。

你要做什么输入 / 选择得到什么
首次选择语言1 / 21 为中文，2 为 English；之后进入主菜单。
以后重新打开终端输入 sb打开管理菜单。
切换语言f → 1重新选择中文或 English。

2. 搭建节点、导入客户端

你要做什么依次选择得到什么
搭建 Realitya → 1安装 Reality + Vision，默认 TCP 443；无需自购域名。
搭建 HY2a → 2安装 Hysteria2，默认 UDP 443；自签证书需在客户端配置信任。
同时安装两种协议a → 3安装 Reality + HY2，分别使用 TCP / UDP。
使用其他安装端口a → 6 → 3选择协议并自定义监听端口。
已有节点追加协议a → 5 → 4追加 Reality 或 HY2，保留现有节点凭据。
安装前检测（不安装）a → 7检查系统、APT 锁、依赖、TCP/UDP 端口、Reality 握手与下载网络；失败项先处理。已有 HY2 用 a → 5 → 4 追加 Reality。
查看节点链接b → 1查看链接与客户端格式，复制到对应客户端导入。
查看节点参数（请保密）b → 7查看 UUID、公钥、Short ID、握手网站和目标。重要数据保存在本 VPS，请勿公开；务必通过 d → 2 安装并启用防火墙，先放行 SSH 和实际节点端口。
导出客户端配置b → 2导出订阅、Mihomo YAML、sing-box JSON 等本地文件。
小火箭扫码导入b → 4显示各节点二维码，用 Shadowrocket 扫码导入。

初次搭建按 a → 1 安装，再核对防火墙，最后用 b → 1 或 b → 4 导入。客户端开启连接后访问网页测试。

3. 防火墙：安装后直接继续开启

从主菜单输入 d → 2 进入 UFW。下表数字直接在 UFW 菜单输入。

你要做什么选择得到什么
安装防火墙1安装 UFW 软件包，尚未开启防火墙。
开启防火墙2核实 SSH 端口，放行 SSH 和实际节点端口后启用。
关闭防火墙3停用 UFW。
查看是否开启4显示运行状态和端口放行规则。
额外放行端口5填写端口，再选择 TCP 或 UDP。
删除放行规则6按显示的规则编号删除指定规则。
返回上一层0返回“服务器与网络”；再输入 0 回到主菜单。

连续操作：进入 UFW 后选 1 安装，完成后直接选 2 开启，再选 4 查看状态。服务商控制台的安全组 / 云防火墙需另外放行实际 TCP / UDP 端口。

4. 日常管理与优化

你要做什么依次选择得到什么
查看状态 / 配置检查c → 1 → 1
c → 1 → 6		分别查看服务状态、检查配置是否有效。
重启节点服务c → 1 → 3校验配置后重启 sing-box。
查看错误日志c → 2显示近期日志，排查启动或连接错误。
改端口 / 地址 / SNIa → 5再选 1 改端口、2 改地址、3 改 SNI；修改后重新导入客户端。
修改节点名称b → 3修改客户端显示名称，保留 UUID / 密码。
启用 BBR + FQd → 4检查内核支持并调整系统 TCP 参数；实际效果取决于线路。
查看资源占用d → 7查看进程、内存与负载。
检测当前 Reality 网站d → 12 → 1读取当前握手目标，检查 DNS、TCP、TLS 1.3、证书与 HTTP/2，明确显示通过或失败原因。
检测自定义握手网站d → 12 → 2填写域名或 域名:端口，可单独指定 SNI；只检测，不修改节点。
更换 Reality 握手网站d → 12 → 3选择常用网站或自定义 SNI / 目标；检测通过后输入 y 应用，同步管理员与受限用户，保留 UUID、密钥、端口及用量。完成后重新导入客户端节点。
管理用户与配额g进入后：1 初始化、2 添加、3 用量、9 个人节点 / 二维码。
申请域名证书e → 6进入 ACME 证书申请与续签菜单。
更新管理脚本e → 4检查正式版，确认后更新 SKYBYTE 管理菜单与功能。
更新 sing-box 核心e → 1选择本版测试核心、最新稳定版或指定版本。
备份 / 恢复e → 2
e → 3		分别备份或恢复配置；备份含私钥，需妥善保存。
卸载脚本与节点f → 3备份后卸载托管服务与配置。

专业流媒体 / 回程 / 测速

报告统一黄色显示。流媒体结果按平台、状态、地区、类型和说明五列对齐，长文本自动换行；vnStat、资源和网络状态等报告也使用黄色。

先进入 d → 8，再按下表选择。检测工具按需下载并校验，菜单打开时不运行测试。

想做什么菜单选项得到什么结果
全球流媒体 + AI（IPv4）1UnlockTests 检测全球平台、ChatGPT、Gemini 等，显示状态、地区和原生/DNS/代理类型。
检测 IPv6 / 双栈2 / 3分别检测 VPS 直连 IPv6 或 IPv4+IPv6。
检测 WARP 出口4先验证本机 WARP，再通过 SOCKS5 检测；实际出口地址族由代理决定。
直连与 WARP 对比5分别输出直连 IPv4 和 WARP 的平台检测结果。
全地区平台检测6VPS IPv4 检测全部地区平台；范围较大，未完成项会标明。
三网回程 / 路由7融合怪 Go 检测 VPS 到探测目标的回程/路由，不进行带宽测速。
三网带宽测速8输入 y 后运行，可能消耗较多 VPS 流量并临时占用带宽。
综合网络测评9基础、流媒体、IP 信息、回程与测速；关闭结果上传及 CPU/内存/磁盘压力测试。

结果保留上游判定，未知或超时不会冒充成功；不能保证账号资格或实际播放。流媒体报告仅保存在 VPS，综合检测关闭上传。

5. WARP 分流：按需开启

从主菜单输入 d → 9 进入 WARP。下表数字直接在 WARP 菜单输入。

你要做什么选择得到什么
安装官方 WARP1安装本机代理，按提示配置出站。
使用已有代理2填写已有的本机 SOCKS5 端口。
导入 WireGuard3导入你自己的 WARP WireGuard 配置。
选择要分流的平台4选择 Netflix、Disney+、ChatGPT、Gemini 等平台。
切换出站模式5直连、全局 WARP 或指定域名分流。
管理分流规则6检查出口、更新规则或应用当前列表。
检测双栈出口7查看 IPv4 / IPv6 出口情况。
专业检测菜单8打开专业流媒体/回程/测速菜单，再选 5 对比直连与 WARP。

节点先直连成功，再按需配置 BBR、WARP 或多人配额。配置检查通过不等于公网已连通。
