Xray 一键脚本功能对照表

发表于2026-10-24|更新于2026-10-26|技术教程 / 网络链路
|浏览量:
想用什么功能，就按表格选择。
适用 SKYBYTE Xray Manager v0.1.20。主菜单用字母，子菜单用数字，确认输入 y。
a → 1 表示输入 a、回车，再输入 1、回车。路径均从主菜单开始；已经在子菜单时直接选择编号。操作后留在当前菜单，0 返回上一层，主菜单 q 退出。

1. 安装节点、导入客户端

用 root 登录 Ubuntu/Debian VPS，到Xray 安装入口页复制命令执行。安装后输入 xr 打开管理菜单。

你要做什么依次选择得到什么
搭建 Reality + Visiona → 1安装 TCP / Reality 节点，默认 TCP 443，启用 Vision flow。
搭建 XHTTP + Realitya → 2默认 TCP 443，无需自己的域名证书；按提示设置路径和模式。
搭建 XHTTP + TLS / CDNa → 3默认 TCP 2053；需自己的域名、可信 fullchain 和匹配私钥。
查看链接与客户端配置b查看节点链接、订阅与 Xray 客户端配置文件位置。
查看节点参数（请保密）p按节点查看 UUID、公钥、Short ID、握手网站和目标；TLS 节点标明不适用。重要数据保存在本 VPS，请勿公开；务必通过 l → 2 安装并启用防火墙，先放行 SSH 和实际节点端口。
扫码导入节点c显示本地生成的节点二维码；客户端需支持相应协议。
切换语言j选择 1 为中文、2 为 English。
查看使用说明i显示脚本使用帮助。

连接地址填写本 VPS 的公网 IP 或域名。每种节点需使用不同的空闲 TCP 端口；安装时可自行修改，系统防火墙与云安全组都要放行实际端口。

2. 服务控制与节点编辑

你要做什么依次选择得到什么
查看运行状态d → 1查看 Xray 服务是否运行。
启动节点服务d → 2启动 Xray 服务。
停止节点服务d → 3停止 Xray；当前节点连接会中断。
重启节点服务d → 4重启 Xray 服务。
检查配置d → 5检查服务端配置；不代表公网或 CDN 已连通。
查看日志d → 6显示近期服务日志，排查启动或连接错误。
修改节点名称e → 1选择协议后重命名节点。
删除某种协议e → 2选择协议后删除；重新安装会生成新凭据。
更新 TLS 证书e → 3为 XHTTP-TLS 更换可信 fullchain 与匹配私钥。
修改地址 / 端口 / 路径e → 4回车保留原值；保留 UUID / 密钥。改完从 b 获取新链接。

3. 防火墙与 BBR

从主菜单输入 l 进入防火墙 / BBR。操作后可直接选择下一项。

你要做什么依次选择得到什么
查看防火墙状态l → 1查看 UFW / firewalld 状态及规则。
安装并开启 UFWl → 2核实 SSH 端口，放行所需端口，再安装并启用 UFW。
放行全部节点l → 3在已开启的防火墙中放行实际节点 TCP 端口。
放行指定端口l → 4输入需要放行的 TCP 端口。
仅停用 UFWl → 5 → 1停用防火墙，保留软件包和规则配置。
卸载 UFW，保留配置l → 5 → 2停用后卸载软件包，保留规则配置。
卸载并清除 UFW 配置l → 5 → 3卸载软件包并清除规则配置，清除后不可恢复。
查看 BBR 是否开启l → 6显示 BBR 状态、当前拥塞算法和队列。
启用 BBR + fql → 7保存原参数并尝试启用；实际效果取决于内核与线路。
恢复 BBR 原参数l → 8恢复本脚本启用 BBR 前保存的系统参数。

连续操作：进入 l 后选 2 安装并启用 UFW，完成后直接选 1 查看状态，无需回主菜单。

4. WARP 分流与平台检测

你要做什么依次选择得到什么
安装官方 WARPn → 1安装本机代理，按提示选择分流平台。
使用已有代理 / 选择平台n → 2填写 SOCKS5 端口，再选 Netflix、Disney+、ChatGPT、Gemini 或自定义域名。
关闭 WARP 分流n → 3本项目恢复直连，保留 WARP 软件。
验证 WARP 出口n → 4检查本机代理实际出口与 WARP 连接状态。
对比平台响应n → 5对比直连与 WARP；检测结果不保证实际播放或账号可用。
检测当前 Reality 网站o → 1检测 TCP/Reality 与 XHTTP/Reality 的握手目标，检查 DNS、TCP、TLS 1.3、证书与 HTTP/2。
检测自定义握手网站o → 2填写域名或 域名:端口，可单独指定 SNI；明确显示通过或失败原因。
更换 Reality 握手网站o → 3选择已安装的 Vision 或 XHTTP + Reality，再选常用网站或自定义目标；检测通过并输入 y 后应用，保留 UUID、密钥、端口和路径。完成后重新导入所选节点。

5. 更新、备份与卸载

你要做什么选择得到什么
更新管理脚本m检查并更新管理脚本；成功后重新输入 xr。
更新 Xray 核心f校验并更新官方核心，保留已有节点。
备份配置g生成配置备份；备份包含私钥与凭据。
恢复配置h输入可信备份路径，校验后恢复。
卸载 Xray 管理器k备份后移除托管节点与管理器，保留备份及外部文件。
